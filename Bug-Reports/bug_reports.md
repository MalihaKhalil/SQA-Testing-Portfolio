## Bug Report Template

| Field | Description |
|---|---|
| Bug ID | Unique defect identifier |
| Title | Short description of the issue |
| Severity | Impact of the issue |
| Priority | Urgency of fixing the issue |
| Environment | Browser / OS |
| Steps to Reproduce | Steps to reproduce the issue |
| Expected Result | Expected application behavior |
| Actual Result | Observed application behavior |
| Status | Open / Fixed / Retest / Closed |
